# Getting started

Two steps, about 15 minutes the first time (mostly downloads):

1. **[Installation](installation.md):** get the code, start Minecraft with the McBot mod, set up Python.
2. **[Your first script](first-script.md):** connect, move, take a picture, read the player's state.

Then pick what you need:

- the **[Guides](../guides/index.md)** show how to do one thing (move, read blocks, find entities, build…);
- the **[Concepts](../concepts/index.md)** explain how things work (ticks, coordinates, errors, limits);
- the **[API reference](../reference/index.md)** lists every class and method with its exact parameters.
